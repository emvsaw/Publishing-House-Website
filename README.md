# Author Website Template

A fully working author website template for indie authors. No coding or tech skills required — Claude does the work.

## 🚀 Quick Start

**Open [START-HERE.md](./START-HERE.md) first.** It walks you through picking one of two workflows and setting up your site.

## Two Workflows to Choose From

You pick whichever fits how you want to work:

### 🅰️ Path A — GitHub Auto-Deploy
Your site auto-publishes to the internet whenever you make a change. Zero terminal, fully automated.
→ [GITHUB-AUTO-DEPLOY.md](./GITHUB-AUTO-DEPLOY.md)

Uses: Claude Desktop + GitHub Desktop + Cloudflare Pages

### 🅱️ Path B — Claude Code + Upload to Your Host
Customize locally, preview in your browser, upload the finished files to whatever host you use (Bluehost, SiteGround, GoDaddy, etc.). Requires opening a terminal just to launch Claude Code.
→ [CLAUDE-CODE-AND-UPLOAD.md](./CLAUDE-CODE-AND-UPLOAD.md)

Uses: Claude Code + your existing web host

## What's Included

- **3 example pen names** with fully themed landing pages (thriller, paranormal romance, cozy mystery)
- **Homepage** with filterable book grid
- **Newsletter integration** with MailerLite
- **Mobile-optimized** — responsive on phone, tablet, and desktop
- **Full guide** (`Author-Website-Builder-Guide.docx`) with copy-paste prompts for every page type
