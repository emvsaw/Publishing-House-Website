# 👋 START HERE

### Welcome! You're about to build your own author website.

This template contains a fully working website with 3 example pen names (Kate Thomas, Madison Lane, Briar Morgan). You'll use these as examples, then customize everything for **your** pen names, books, and brand.

**No coding required.** Claude does all the work — you just tell it what you want in plain English.

---

## 🛤️ Two Ways to Build Your Site

Before you dive in, pick the path that fits how you want to work. You can always switch later.

### 🅰️ Path A — GitHub Auto-Deploy (most automated)

Your site lives on GitHub and auto-updates on the internet every time you make a change. Once set up, you make edits and they go live automatically within ~90 seconds.

- **Uses:** Claude Desktop app + GitHub Desktop app + Cloudflare Pages
- **Terminal needed:** Never
- **Best for:** Students who want a "set it and forget it" workflow
- **Tradeoff:** 30-minute setup, requires creating GitHub + Cloudflare accounts

👉 **Follow [GITHUB-AUTO-DEPLOY.md](./GITHUB-AUTO-DEPLOY.md)**

---

### 🅱️ Path B — Claude Code + Upload to Your Host (simpler, manual)

You customize your site locally with Claude Code, preview it in your browser, and upload the finished files to whatever web host you use (Bluehost, SiteGround, GoDaddy, etc.). No GitHub required.

- **Uses:** Claude Code + your existing web host
- **Terminal needed:** Only to launch Claude Code (one command — `claude`)
- **Best for:** Students who already have a web host, or who want the simplest understand-everything workflow
- **Tradeoff:** You manually re-upload files after each change

👉 **Follow [CLAUDE-CODE-AND-UPLOAD.md](./CLAUDE-CODE-AND-UPLOAD.md)**

---

## 🤔 Not Sure Which to Pick?

**Pick Path A if:**
- You want your site to update automatically whenever you make changes
- You're OK creating a free GitHub account
- You don't already have a web host, or you're fine using Cloudflare's free hosting

**Pick Path B if:**
- You already pay for web hosting (Bluehost, SiteGround, GoDaddy, HostGator, DreamHost, etc.)
- You prefer a simpler workflow even if it means manually uploading files
- You don't want to learn GitHub

Both paths end with a live website. They just get there differently.
