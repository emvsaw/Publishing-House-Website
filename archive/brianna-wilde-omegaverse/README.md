Brianna Wilde's pen name was repositioned from omegaverse/romantasy to dark mafia
romance (The Velvet Reckoning series) on 2026-11-15. This folder preserves the
omegaverse content so it can be restored or reused for a future pen name/series.

Contents:
- `brianna-wilde-page.astro.bak` — the original landing page
  (`src/pages/authors/brianna-wilde.astro`), themed for the Harbor House Pack series.
- `brianna-wilde-author.md.bak` — the original author bio/frontmatter
  (`src/content/authors/brianna-wilde.md`).
- `books/` — the 5 original book entries (Marked, Leaked, Severed, Fractured, Named),
  originally at `src/content/books/`.
- `covers/` — the 5 original cover images, originally at
  `public/images/covers/brianna-wilde/`.

To restore: move the files back to their original paths listed above (dropping the
`.bak` suffix), and swap `src/pages/authors/brianna-wilde.astro` back to this version.
